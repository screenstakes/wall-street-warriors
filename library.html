What is not in here, and why

One rule: a page is in this library only if it is the current version and somebody still needs it. Drafts, superseded plans and to-do lists against files we no longer edit are left out on purpose, because a link to a stale page is worse than no link.

Earlier versions of several of these lived as private links that only Michael could open. Where that happened, the page here is the newer one — the private copies are out of date and should not be shared.
