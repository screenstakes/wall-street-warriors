    Federico — Trade log and the rules
  3. Then replace the check so it can never go stale again. Click E6, paste this, then drag the little square in its corner down to E9:
    =IF($C6="","Not connected",IF(ISERROR($D6),"Click D"&ROW()&", press Allow access",IF(ISNUMBER(SEARCH($A6,$D6)),"Connected ✓","Wrong file: that link is "&$D6)))
Why this keeps breaking. The old check had each person's name typed into the formula, so when you swapped Caleb and Federico's jobs in September the names in column A moved but the formulas did not. The new one reads the name out of column A, so you can reorder those rows freely and it will always be right.
